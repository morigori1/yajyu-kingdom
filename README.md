# 野獣キングダム 〜王道を征く〜

Kingdom Two Crowns 風サイドビュー領地防衛（ブラウザ単体 HTML）。  
舞台は下北沢（自称）・真夏・汗・湿度114514%。PG-13 淫夢パロディ。実在人物・団体とは無関係。

**Play:** https://morigori1.github.io/yajyu-kingdom/

著作権のある Steam / 公式ゲームアセットは不使用。  
キャラ顔ドットは [真夏の夜の淫夢Wiki](https://wiki.yjsnpi.nu/wiki/%E3%83%A1%E3%82%A4%E3%83%B3%E3%83%9A%E3%83%BC%E3%82%B8) 掲載写真を許可のもと取得し、顔周辺のみ縮小ドット化（ポルノ実写のままは不使用）。

**語録方針:** パロディ語録のみ。ストーリーは説明せず、空耳・括弧ツッコミ（1行1つ）・114514/810/24・断片会話で「わかる人にはわかる」トーン。過度に性的な表現は避ける。王冠＝「王道を征く」維持。  
世界観・章立て・敵名は `lore-share-from-td.md`（野獣TD共有）およびカードバトル側トーンと整合。


## グラフィック（Kingdom Crowns級・段階拡充）
1. **パレット統一** — CSS `--yk-*` と `PAL`／章アクセント同期（金・薔薇・木・草・夜）
2. **章風景テーマ** — 下北路地／井の頭水面／新宿ネオン／外縁尖塔（`CHAPTER_THEME`）
3. **キャラ／塔アニメ** — 歩行砂塵・マント揺れ・トリオ3体・砲台座・発射リング
4. **昼夜・天候レイヤ** — フォグ／ヒートヘイズ／粒子／夕焼け帯／夜ビネット（`drawWeatherLayers`）
5. **UI枠** — キャンバス多重縁・HUD／パネル角オーナメント・章テーマ框色


## 収集・実績（completionism）
関係パネル内サブタブで閲覧・装備。旧セーブは欠落フィールドを空で補完（`yk-save-v1` 互換）。

| 系統 | 内容 |
|---|---|
| **語録図鑑** | 章ストーリー／関係会話が表示されると自動収録 |
| **ロケ写真** | 聖地解放・撮影ロケ・章隠しで追加（📷） |

## ロケ日程・任務（schedules / missions）

| 系統 | 内容 |
|---|---|
| **日次** | 聖地解放数に応じ最大4本。共有語録ロケ／崩壊観測ロケを章に応じて差し込み |
| **週次** | Day7区切り。連日撮影／汗の王／崩壊の片鱗（完了で微粒子砲など） |
| **章任務** | 下北密着／井の頭池畔／新宿巡回／外縁微粒子観測（各1回） |
| **共有語録** | カード側：ありますあります／流行らせコラ！／クゥーン…／微粒子レベルで存在している／すっごい綺麗…／1日…350円！／いいかな？（念押し）。崩壊系も図鑑（田所浩二は別枠） |

## 関係値拡充（bonds）
関係パネルで NPC（後輩／撮影班／街）を選び、会話分岐・ギフト・共同ロケ。閾値で世界イベント発火→語録図鑑・塔スキン連動（`yk-save-v1` 互換・旧セーブは空補完）。

| 系統 | 内容 |
|---|---|
| **会話分岐** | 関係値帯で台詞変化。1日1回／NPC。湿度・撮影カットにも寄与 |
| **ギフト** | コイン消費・1日1種。カード語録（すっごい綺麗…／350円／念押し）解放 |
| **共同ロケ** | 解放済み聖地で進捗型。完了で写真・語録・絆 |
| **閾値Evt** | 810円の自販機が出現／黒塗りの高級車が急ブレーキ／語録の限界集合 ほか |
| **塔スキン** | 自販機砲・黒塗りの砲（関係Evtでも解放） |

### スマホ
画面**下端**の仮想パッド：◀ ▶／**内政**／**軍事**／🪙支払う／（）迫真  
上端は HUD・湿度・ストーリー／トースト専用（パッドと帯を分離、被り回避）。

パネルはカード枠UI（内政／軍事／ロケ日程／関係・やりこみ）。

### モバイル／タッチUI（セーフエリア・縦持ち・品質連動）
ノッチ／ホームインジケータ対応とタッチ誤操作防止を強化（既存セーブ・内政／軍事／関係は不変）。

| 項目 | 内容 |
|---|---|
| **セーフエリア** | `viewport-fit=cover`＋CSS `env(safe-area-inset-*)`。HUD／パッド／パネル／チップに反映 |
| **パネル重なり** | 開時 `#wrap.ui-panel` で仮想パッド非表示・チップ／トースト位置を底上げ。カード高 `--panel-max-h` 拡大 |
| **タッチパッド** | `setPointerCapture` で指ずれ保持。`touch-action`／`gesturestart` 抑制。粗いポインタは min 48px |
| **フォント／ボタン** | `--hud-fs`／`--ui-fs`／`--pad-btn-h`／`--btn-min-h`。縦持ちで clamp 拡大 |
| **縦持ちレイアウト** | `orientation: portrait` と `applyUiLayout()`（`ui-portrait`）。超縦長（≤400px）でパッド微増 |
| **品質ティア連動** | `html[data-gfx=low|high]`。低画質＋縦持ちタッチはパッド高を抑えキャンバス領域確保。影簡略化 |
| **visualViewport** | モバイルブラウザUI開閉時に `fitCanvas` 再計算 |

### タイトル

## バランス／プレイ感（テンポ・経済・攻勢・熱中症・補給・関係）

機能追加は最小。既存セーブ `yk-save-v1` 互換のまま数値とセーフティを調整。

| 項目 | 調整 |
|---|---|
| **昼夜テンポ** | `syncCycleLengths`：序盤の昼を長め、夜は波数に合わせて長さを確保。昼選択は `dayLength` 比で発火・取りこぼし防止 |
| **コイン経済** | 朝ボーナスは日数ソフトキャップ＋序盤／攻勢の微増。補給線稼働で＋1 |
| **攻勢難度** | `combatDayScale` で敵HP／速度／波／壁ダメをソフトキャップ（エンドレスの無限強化を抑制） |
| **熱中症** | 上昇を緩和、気絶短縮・移動残し。補給線・物資でリスク抑制 |
| **補給線** | 壁応急・被弾軽減・熱中症↓をわずかに強化。無効な終点聖地は自動クリア |
| **関係ゲート** | 会話＋／ギフト・共同ロケ・閾値Evtの必要関係を下げて到達をなめらかに |
| **セーブ欠け** | パネル／昼選択中の `saveGame` を許可。ロード時に bond／heat／civil を ensure |

## 真夏・天候（heat / summer weather）
湿度・汗・熱中症リスクを軸に、朝の真夏イベントと天候レイヤが連動（`yk-save-v1` 互換・旧セーブは欠落を既定補完）。

| 系統 | 内容 |
|---|---|
| **湿度／汗** | 高湿度で移動↓・砲台間隔↑。汗ドロップはミッション／ロケで蓄積 |
| **熱中症リスク** | 湿度・イベントで増減。高リスクでひるみ（`heatStunT`）。Tでアイスティー、切れ時は麦茶 |
| **冷却** | アイスティー／麦茶（在庫0–3）／昼・内政のアイス／夕立。麦茶ギフトで後輩絆↑ |
| **真夏Evt** | `HEAT_EVENT_DEFS` 10種。`LORE.heatStory` が朝ストーリーに乗る |
| **ビジュアル** | `drawWeatherLayers`：ヒートヘイズ／夕立鉛空／麦茶琥珀／熱中症赤縁／湯気／アイス涼帯／焼肉煙／洗濯白帯 |
| **任務** | 日次「真夏密着ロケ」／週次「真夏の王」。実績：Evt種・麦茶杯数・夕立・アイス・リスク冷却 |

操作: **T**＝アイスティー（切れ→麦茶）。内政で茶・麦茶補給／アイス購入。


## 音（SFX／簡易BGM）
外部音声ファイルなし。Web Audio API で短音・ノイズ・パッドを合成（`AUD`）。

| 系統 | 内容 |
|---|---|
| **SFX** | コイン／砲台／着弾／UIクリック／語録ポップ／支払／茶／夜襲／夜明け／夕立／熱中症／勝敗／括弧ツッコミ |
| **BGM** | タイトル／昼／夜で正弦＋三角の薄いパッド（モード切替時のみ再生成） |
| **天候** | 夕立中のみループノイズ（終了でフェードアウト） |
| **ミュート** | 画面右下「音:ON/OFF」。`localStorage` キー `yk-mute`（`'1'`=OFF）。ゲームセーブとは独立 |
| **制約** | ブラウザの自動再生制限のため初回タップ／キーで AudioContext 解錠。連打は内部スロットル |

既存の `requestAnimationFrame` ループは BGM 同期を約1.2秒間隔で呼ぶのみ（重い処理なし）。
