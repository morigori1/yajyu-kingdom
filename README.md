# 野獣キングダム 〜王道を征く〜

Kingdom Two Crowns 風サイドビュー領地防衛（ブラウザ単体 HTML）。  
舞台は下北沢（自称）・真夏・汗・湿度114514%。PG-13 淫夢パロディ。実在人物・団体とは無関係。

**Play:** https://morigori1.github.io/yajyu-kingdom/

著作権のある Steam / 公式ゲームアセットは不使用。  
キャラ顔ドットは [真夏の夜の淫夢Wiki](https://wiki.yjsnpi.nu/wiki/%E3%83%A1%E3%82%A4%E3%83%B3%E3%83%9A%E3%83%BC%E3%82%B8) 掲載写真を許可のもと取得し、顔周辺のみ縮小ドット化（ポルノ実写のままは不使用）。

**語録方針:** パロディ語録のみ。ストーリーは説明せず、空耳・括弧ツッコミ（1行1つ）・114514/810/24・断片会話で「わかる人にはわかる」トーン。過度に性的な表現は避ける。王冠＝「王道を征く」維持。  
世界観・章立て・敵名は `lore-share-from-td.md`（野獣TD共有）およびカードバトル側トーンと整合。

## 操作

### PC
| キー | 効果 |
|------|------|
| A/D・←→ | 移動 |
| スペース／クリック | 支払い or コインドロップ |
| Q / E | 括弧ツッコミ（敵スロー） |
| T | アイスティー飲用 |

### スマホ
画面**下端**の仮想パッド：◀ ▶／🪙支払う／（）迫真  
上端は HUD・湿度・ストーリー／トースト専用（パッドと帯を分離、被り回避）。  
聖地付近／部室バス停で支払い → **ロケバス**発車（撮影班が聖地を行き来）。

### タイトル
| ボタン | 効果 |
|------|------|
| いいよ！こいよ！（新規） | セーブを消して Day1 から |
| つづきから（セーブ） | `localStorage` のオートセーブをロード（夜セーブは朝へ軟着陸） |

敗北画面でもセーブが残っていれば「つづきから」可。章クリア後は攻勢セーブ可（新規のみ削除）。

## 内政 / 軍事 / 攻勢

### 内政
| 要素 | 内容 |
|---|---|
| 作業員 | 雇う・聖地配置。内政Lvで人数上限↑・収入↑ |
| 聖地施設 | 解放時Lv1、強化で朝収入・バス収益↑ |
| 810銀行 | 預け／引出／朝利息。運用Lvで利率↑ |
| 内政整備Lv | 収入・自動ロケバス頻度 |
| ロケバス（黄） | 部室↔聖地の撮影班巡回 |

### 軍事
| 要素 | 内容 |
|---|---|
| バリケード | 建設／石強化で境界拡張 |
| 砲台 | 設置・個別Tier（射程／火力） |
| 先鋒 | 侵攻バス搭乗で拠点ダメージ増 |
| 軍事教練Lv | 砲台間隔短縮 |
| 侵攻バス（赤） | 敵拠点へ突撃・破壊 |

### 攻勢モード
平定カット後「攻勢続行」→ 隣の敵拠点が出現。破壊で次章聖地が解放可能。クリア後もセーブ継続。
