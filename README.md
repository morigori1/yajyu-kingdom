## 独自メカニクス（クローン差分）

Kingdom骨格（サイドスクロール・昼夜・壁・雇用・夜襲）は維持しつつ、淫夢／野獣ワールド固有のシステムを中程度追加。

| システム | 遊びへの影響 | 操作・発生 |
|---|---|---|
| **湿度・汗ゲージ** | 高（≥80）で移動↓・砲台遅延／低（＜20）で朝の収入減。適湿は朝ボーナス | 移動・夜・敵近接で上昇。部室近くで低下。HUD中央バー |
| **アイスティー** | 湿度を大きく下げ、わずかに部室回復 | 部室左で購入（在庫最大3）。**T**または在庫消費 |
| **114514／聖数コンボ** | 夜の連続撃破5で＋2、8・10で＋1。所持が8/10/24/81で＋1 | 撃破で自動 |
| **昼のミニ選択** | 毎昼1回：屋上焼肉／部室お茶／草むら漁り | 昼タイマー中盤にパネル |
| **たかり後輩** | 壁より先輩に寄り、近接でコイン窃盗 | 夜ウェーブに混在。倒すと追加ドロップ気味 |
| **眼光デバフ** | 眼光系が近いと移動↓・砲台さらに遅延 | ボス／眼光名の敵。HUDに「眼光…」 |
| **810銀行** | 預けた分に朝利息（約12%、8枚以上で＋1） | 部室右で預け／引出 |
| **括弧ツッコミ** | 周囲の敵を約2.6秒スロー | **Q**またはパッド「（）迫真」（CD約11秒） |

バランスは「最小〜中」：クリア条件（Day7＋両側石壁）とコイン経済は大きく壊さない範囲。

## ドット＆アニメ（CRONWS級）

- 微細ピクセル＋**自動アウトライン／陰影パレット**、nearest-neighbor 拡大
- 歩行4フレ・炎4フレ・コイン回転・旗はためき・パララックス丘／草タイル
- TD v29敵色分け: 遠野笑顔（桃暖）／ンギモ（緑）／こ↑こ↓（シアン紅）／MUR（虚空＋シアン視線）
- 先輩：歩き2フレ＋待機／王冠は常時（王道を征く）／高湿度で汗ドット
- 砲台後輩：待機／射撃フラッシュフレ
- 敵：通常・たかり・眼光で別パレット＋2フレ歩行。スタン時に（）表示
- 壁：レンガ積み＋旗のはためき。夜は全体に微揺らぎ
- 部室の炎：3フレ＋火粉。撃破バーストFX
