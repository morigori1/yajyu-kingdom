## グラフィック（真夏下北パロディ・Kingdomシルエット維持）
舞台は「下北沢の自称・真夏」の遊び。実在の番地や私邸は描かない。中世ファンタジーの城・魔法陣から離れ、部室・路地・屋上・自販機・電柱の風景にする。Kingdom風の横スクロール可読性とパララックスは残す。

1. **真夏パレット** — 白い熱昼／琥珀の夕／湿った青緑夜。自販機シアンと窓明かり。章ごとに別色（路地／池／ネオン／外縁）
2. **章風景** — 下北は住宅壁と電柱、井の頭は水面とヨシ、新宿外縁はネオン窓、外縁は測定塔と熱気（`CHAPTER_THEME`／`drawStreetLayer`）
3. **拠点と巣** — 部室コアは七輪＋掲示板。防衛は机・波板・コンクリート。塔は屋上スピーカー。巣口は半開きシャッターと室外機の隙間（役割・数値は不変）
4. **昼夜・天候** — ヒートヘイズ／湿度もや／夜の自販機光（`drawWeatherLayers`）
5. **UI** — 部室掲示板の枠。重要文字は Noto Sans JP。コスト／現地払い／HP／危険表示は大きく残す
6. **語録の置き方** — 810／114514／アイスティー／「あります」は小物と看板の端だけ。壁紙にはしない

### 真夏下北パス：出荷済み／残り
**出荷済み（master `8f896b1`／PR #3+#4）:** 章パレット、電柱・室外機・自販機の街層、部室七輪＋掲示板、机／波板／コンクリート壁、屋上スピーカー砲台、シャッター巣口、掲示板UI＋Noto Sans JP、顔の肖像メダル廃止、店サークルは射程内のみ。  
**残り（見た目の負債）:** 低画質自動判定でディテールが間引かれる、プレイ昼の夕空は日暮れ直前だけ琥珀、スクリーンショットのドットは縮小で潰れる。テーマ作業の未コミット分はない。

## モーション
静止画の平行移動だけにはしない。`dt` で歩行位相・予備・硬直を進める。`prefers-reduced-motion` と低画質では振幅だけ落とす（予備と撃破は残す）。画面揺れをアニメの代わりにしない。

- **先輩** — 加速／減速、歩きと走りで歩幅が違う、旋回の傾き、Qで腕が上がる。顔と王冠は頭に残す
- **チャリ／スクータ／ホース** — 車輪のスポーク、スクータの傾きと排気、ホースのギャロップと頭・尾。乗車中も顔は読める
- **敵** — 出現（口から）、歩行（俊足はホップ、盾は重い踏み）、予備、放出、被弾、短い撃破。盾は構え／のけぞり／割れ。遠野の「！」は実際に弾が出るタイミング。応援の旗はバフと同期。ボスは王冠パルス＋蓋＋笑顔弾

### 探索 第2弾（遭遇・再訪・潜入）
- **新スポット**：西 −1760「銭湯跡の煙突」（章2〜）、東 2820「水のないプール」（章3〜）。探索地点は全14か所。

### たき火の残響（序盤ワンクエスト）
Day1の部室そばで完走できる一本の冒険。遠端まで歩かなくてよい。支払いなし。

1. **異変** — たき火の影が西へ伸びる（開始十数秒以内）
2. **手がかり** — 西の路地落書き「こ↑こ↓じゃなくて　こ→こ←」
3. **選択** — 東の焼けたロケ弁箱。【開ける】安全／【溝へ】湿度↑・🪙多め。どちらも穴が開く。左の扉で戻れる
4. **裏穴** — 部室のすぐ西。3部屋は見た目も操作も違う（湯気／裏返った部室／残響の間）
5. **残響鈴** — 未踏地点がたき火色で揺れる・霧が薄い・草むら漁りが鋭い・日暮れは部室へ急げる。重複入手なし

関係パネルの【日誌】に座標なしの手がかりが段階で残る。日暮れ3秒前は地上へ戻される。`yk-save-v1` 互換（旧セーブは空補完、新規でリセット）。

平定カット後「攻勢続行」→ 隣の敵拠点が出現。破壊で次章聖地が解放可能。クリア後もセーブ継続。編成と補給が侵攻ダメージに反映。

## 真夏・天候（heat / summer weather）
湿度・汗・熱中症リスクを軸に、朝の真夏イベントと天候レイヤが連動（`yk-save-v1` 互換・旧セーブは欠落を既定補完）。

| 系統 | 内容 |
|---|---|
| **湿度／汗** | 高湿度で移動↓・砲台間隔↑。汗ドロップはミッション／ロケで蓄積 |
| **熱中症リスク** | 湿度・イベントで増減。高リスクでひるみ（`heatStunT`）。Tでアイスティー、切れ時は麦茶 |
| **冷却** | アイスティー／麦茶（在庫0–3）／昼・内政のアイス／夕立。麦茶ギフトで後輩絆↑ |
| **真夏Evt** | `HEAT_EVENT_DEFS` 10種。`LORE.heatStory` が朝ストーリーに乗る |
| **ビジュアル** | `drawWeatherLayers`：ヒートヘイズ／夕立鉛空／麦茶琥珀／熱中症赤縁／湯気／アイス涼帯／焼肉煙／洗濯白帯 |
| **任務** | 日次「真夏密着ロケ」／週次「真夏の王」。実績：Evt種・麦茶杯数・夕立・アイス・リスク冷却 |

操作: **T**＝アイスティー（切れ→麦茶）。内政で茶・麦茶補給／アイス購入。


## 音（SFX／簡易BGM）
外部音声ファイルなし。Web Audio API で短音・ノイズ・パッドを合成（`AUD`）。

| 系統 | 内容 |
|---|---|
| **SFX** | コイン／砲台／着弾／UIクリック／語録ポップ／支払／茶／夜襲／夜明け／夕立／熱中症／勝敗／括弧ツッコミ |
| **BGM** | タイトル／昼／夜で正弦＋三角の薄いパッド（モード切替時のみ再生成） |
| **天候** | 夕立中のみループノイズ（終了でフェードアウト） |
| **ミュート** | 画面右下「音:ON/OFF」。`localStorage` キー `yk-mute`（`'1'`=OFF）。ゲームセーブとは独立 |
| **制約** | ブラウザの自動再生制限のため初回タップ／キーで AudioContext 解錠。連打は内部スロットル |

既存の `requestAnimationFrame` ループは BGM 同期を約1.2秒間隔で呼ぶのみ（重い処理なし）。

### 現地払い（基本操作）
建設・雇用・強化は **行ってスペースで払う**（原作Kingdomと同じ）。民帳／陣帳は一覧と役割切替で、開いただけでは購入にならない。重なった現地は近い方を払い、無効なら理由を出す。

### 夜の巣
敵は壁の外側の **固定ワールド座標の巣**（または未破壊の敵拠点の口）から夕暮れに灯って出て、歩いて壁へ来る。壊した廃墟からは出ない。画面外は「西／東の巣から来る」。ボスも同じ口。波数と夜の長さは従来に合わせて行進時間を見込む。

### ロケバス（遠路ワープ）
乗り物は近場、**ロケバスは解放済み聖地へのワープ**。部室前か聖地で払うと乗車し、到着で降りる。自動巡回バスは空車（プレイヤーは動かない）。乗車中の乗り物所有／装備／スタミナは維持。
